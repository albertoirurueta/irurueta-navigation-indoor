    <artifactId>irurueta-navigation-indoor</artifactId>
    <version>1.6.0</version>

`https://s01.oss.sonatype.org/content/repositories/snapshots/` as a repository to your build in order to resolve
them.

== Requirements

The library targets Java 21 or newer (see the `maven.compiler.source`/`maven.compiler.target` properties in
`pom.xml`).

== Building from source

[source,bash]
----
git clone git@github.com:albertoirurueta/irurueta-navigation-indoor.git
cd irurueta-navigation-indoor
mvn clean install
